About LoanSense AI

LoanSense AI is an intelligent machine learning web application designed to predict whether a loan application is likely to be approved or rejected based on applicant information.

Machine Learning

Trained using multiple classification algorithms including Logistic Regression, Decision Tree, Random Forest, and KNN.

Performance

Evaluated using Accuracy, Precision, Recall, F1-Score and ROC-AUC.

Batch Prediction

Supports CSV and Excel files for predicting multiple loan applications at once.

Technologies

FastAPI
Scikit-learn
