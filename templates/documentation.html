User Documentation

This guide explains how to use the LoanSense AI application.

1. Single Prediction

Navigate to the Prediction page, fill in the applicant's information, then click Predict. The application will display:

  • Loan Status
  • Confidence Score

2. Batch Prediction

Go to Batch Prediction. Upload a CSV or Excel file containing multiple loan applications.

3. Required Columns

Column Required
Gender ✔
Married ✔
Dependents ✔
Education ✔
Self_Employed ✔
ApplicantIncome ✔
CoapplicantIncome ✔
LoanAmount ✔
Loan_Amount_Term ✔
Credit_History ✔
Property_Area ✔

The application automatically computes:

  • TotalIncome
  • MonthlyLoanPayment
  • LoanIncomeRatio

4. Output

After processing, the application generates a downloadable Excel file containing:

  • Prediction
  • Confidence Score
